## 八、网络配置模块（2026-10-20 补充）

依据：《RoboMaster 赛事引擎联网操作手册（202604）》《RoboMaster 赛事引擎自定义客户端配置说明手册（202604）》。

> [22:13] 这两份手册是主要需要配置的网络需求，两个大模块对应两个配置手册的功能，分开主要目的是 1：能快速让学生判断出来应该是改哪个网卡，然后软件帮改 2：使用完成后可以一键重置环境（恢复默认设置和恢复某个存档点的设置）（存档点可以是开启前询问设置或者是自己手动保存）

> [22:18] 虽然说有线，但是有时候学生还是会无线连接，得兼容，但是发现是无线的时候页面要提示。选手端连自定义客户端可以不用双网卡，直接在赛事引擎的局域网里连接，这个时候显示本机在局域网里的 IP（因为裁判端配置只是给裁判端用，选手端 IP 是 DHCP）
> 赛事引擎配置得选手端配置和裁判端配置分开（选手端没啥特殊配置的话可以省略）

手册参数：

| 模块 | 网卡 | 配置 |
| --- | --- | --- |
| 裁判端 · 方案 1（单网卡 + 路由器） | 局域网网卡 | 静态 `192.168.1.2` / `255.255.255.0`，网关 `192.168.1.1`；主机网线接路由器 LAN 口 |
| 裁判端 · 方案 2（双网卡） | 局域网网卡 | 静态 `192.168.1.2` / `255.255.255.0`，网关留空，跃点 20 |
| | 外网网卡 | 自动获取，跃点 10，网段避开 `192.168.1.0/24` 与 `192.168.12.0/24` |
| 选手端 | 赛事引擎网卡 | 自动获取 IP（DHCP） |
| | 自定义客户端网卡 | 静态 `192.168.12.1` / `255.255.255.0`，网关留空；客户端设备设为 `192.168.12.2` |
| 选手端（可选） | 不用第二块网卡 | 客户端设备接入同一赛事引擎局域网，用本机 DHCP IP 通信 |
| 公共 | 路由器 | LAN 口 `192.168.1.1`、开 DHCP、2.4G、WPA2（密码按手册 12345678） |
| 公共 | 防火墙 | 两本手册均要求关闭 |

实现约定：

- 无线允许使用，但页面提示「建议有线，可能影响稳定性」，不判为错误
- 虚拟网卡不参与角色推荐
- 应用 / 恢复前自动存档；支持手动存档、恢复默认（全 DHCP）、恢复存档点

> [22:24] C

> 选择 C：选手端没有特殊配置项，能省则省。实现为——选手端页内隐藏「赛事引擎网卡」选择行（必然 DHCP，无可选项），默认「同局域网直连」，学生无需选择；只有确实要配 `192.168.12.1` 时才去选第二块网卡。

> [22:28] 裁判端的局域网网卡设置应该默认和选手端赛事引擎网卡是同一张，当选手端赛事引擎网卡检测到配置和裁判端一致的时候应当是警告不是报错
> [22:29] 只警告的原因是可能会有人把选手端和裁判端开在一起，虽然不符合选手端配置但是是可以正常使用的

> 实现：两个模块共用 `DetectEventLanAdapter()` 判定同一张网卡，并记忆手动选择；选手端网卡为 `192.168.1.2` 时判黄色警告，文案说明「同机双开保持原样即可，只跑选手端时再改自动获取」。

> [22:34] 程序里面不应当有提到手册字样的提示语，提示词应当可以显示完整而不是带省略号
> 网卡选择不应有自动推荐选项
> 网卡有什么功能能帮助学生找到自己现在的网卡谁对应谁不，学生电脑上可能有很多网卡，感觉现在无线有线网卡是写死的
> 自定义客户端网络配置界面，当自定义客户端（名字写清楚不要只写客户端）网卡选择赛事引擎网络，直连IP显示该网卡IP，自定义客户端（名字写清楚不要只写客户端）网卡选择另一张独立网卡，IP该网卡现在的IP

> 实现：卡片文案完整换行显示；下拉只列真实网卡；网卡卡片补充 MAC/型号/速率/连接状态，并新增「识别网卡」（拔线后比对状态变化）；无线判定改为类型 + 关键字；选手端统一「自定义客户端」措辞，「自定义客户端直连 IP」跟随第二块网卡的选择。

> [22:41] 我不是让你把选手端局域网网卡和自定义客户端赛事引擎网卡绑死吗
> [22:41] 选择一个另一个也会动

> 实现：裁判端「局域网网卡」与选手端「赛事引擎网卡」共用同一个状态 `_lanNic`，双向联动——任一侧改选，另一侧下拉与检查结果立刻同步；切模块不重置。第二角色下拉排除已选的第一角色网卡。

> [22:54] 识别网卡功能最后应当选择设置为哪个网卡而不是默认。识别网卡功能时间长一点10s，给个提示窗显示倒计时
> 运行状态界面隐藏子进程的运行状态显示，所有子进程都在运行显示运行正常，有没有运行的就警告运行异常（保留一个按钮在角落里，异常检测，点了才能看到）

> 实现：识别网卡改为 10 秒倒计时窗 + 识别后由用户选择设为哪个网卡角色（不默认）；运行状态页默认只显示裁判端/选手端「运行正常 / 运行异常」两张总览卡，右下角「异常检测」按钮展开子进程明细。

> [22:57] 未运行不应当算运行异常，在非异常检测界面不要写子进程的名字

> 实现：总览卡三态（运行正常 / 部分运行 / 未启动），只显示「3 / 4 个程序在运行」，不出现任何子进程名；进程名只在「异常检测」明细里出现。

> [22:59] 一键关闭按钮应该一直在的

> 实现：总览卡下方常驻「一键关闭」（裁判端 / 选手端各一个），明细视图里也保留，两种视图随时可用。
